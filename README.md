# Exercise 2 - Medical Image Classification

This exercise explores different machine learning and deep learning approaches for medical image classification using Chest X-ray and Brain Tumor MRI datasets.

Implemented approaches:

* SVM with PCA
* CNN from scratch
* Transfer Learning using MobileNet

## Folder Structure

### Chest_Xray_SVM

Implementation of PCA + SVM for chest X-ray classification.

### Chest_Xray_CNN

Implementation of CNN from scratch for chest X-ray classification.

### Brain_Tumor_Transfer_Learning

Implementation of transfer learning using MobileNet for brain tumor MRI classification.

## Evaluation Metrics

* Accuracy
* F1-score
* Sensitivity
* Specificity

## Conclusion

This exercise demonstrates the advantages of CNNs and transfer learning over traditional machine learning methods for medical image classification.
