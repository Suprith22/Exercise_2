# Chest X-ray Classification using CNN

## Overview

This project implements a Convolutional Neural Network (CNN) for pneumonia detection using chest X-ray images.

Pipeline:
Image → CNN Feature Extraction → Classification

## CNN Components

* Convolution Layers
* MaxPooling Layers
* Dense Layers
* Dropout
* ReLU Activation

## Methodology

* Images were resized and normalized.
* CNN automatically learned image features.
* Dense layers performed classification.

## Important Concepts

* Convolutional Neural Networks
* Feature Extraction
* Deep Learning
* Medical Image Classification

## Evaluation Metrics

* Accuracy
* F1-score
* Sensitivity
* Specificity

## Observations

* CNN outperformed SVM because spatial image information was preserved.
* Automatic feature learning improved classification performance.
* Performance improved with increasing training data.
